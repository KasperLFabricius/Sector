# PR-08C.1 CT-006 directional-shear acceptance

This matrix is frozen before implementation. The slice owns only the unpublished
CT-006 solver trace. Sector remains `0.91`; torsion, detailing, CT-002 through
CT-005, PR-08D families, presentation, persistence, packaging, workflow,
publication, and version changes are excluded.

| Family, member, or invariant | Frozen acceptance |
| --- | --- |
| Identity and order | Exactly one `ct-006-directional-shear` family and one member are required. Required directions are the positive original-input demands filtered from the immutable tuple `("vx", "vy")`; the mandatory biaxial case is exactly `("vx", "vy")`. Candidate mapping insertion order, active-direction order, direction count, component, and axis are exact. One direction or another family cannot mask a missing required direction. |
| Directions, axes, and faces | `vx` uses bending axis `y`; `vy` uses axis `x`. Signed demand is retained while resistance uses its magnitude. Face order is exactly negative then positive when automatic zero-moment selection requires both; otherwise the original moment/explicit face selects exactly one. Face count, tension sign, associated centroid/origin moment, and governing-face identity are independently reconstructed. |
| Retained methods | The distinct retained methods are EN 1992-1-1:2005, DS/EN 1992-1-1:2005 + DK NA:2024, and the retained 2023 calculation. The 2005 and DK variants share the base equations but have separate v_min and nu rules; 2023 uses its distinct tau/compression-field equations. The local 2023 document remains `96_Published_Not_Implemented` evidence and is not promoted to Danish project applicability. |
| Local sources | Base rules route to `DS/EN 1992-1-1:2004 + A1:2014 + AC:2010`; Danish v_min and nu_v route to `DS/EN 1992-1-1 DK NA:2024`. The local files are the current 2004 base plus AC:2008, A1:2015, AC:2010, and DK NA:2024 records. Exact canonical assigned laws retain their existing source identity; edited/custom values and Sector geometry, selector, and status methods are uncited project sources. |
| Shared inputs | Emit geometry, plastic/shear actions, assigned material-law values, and their exact merged provenance once. Every used leaf reaches the family final. Direction and face chains reference that shared input vector; they are never duplicated. Unrelated CT-002 sweep, SLS, fatigue, torsion, detailing, and bridge inputs are not read. |
| Authoritative branch | Select finite or failed state from original CT-006 inputs and retained low-level mechanics before reading candidate numerical results. A finite branch requires every required direction/face and every governing intermediate to be finite. A failed branch publishes only immutable identity/cardinality and explicit authoritative failure state; omitted, changed, or non-finite candidate failure-only numbers cannot change its bytes. Promotion must traverse complete finite replay. |
| Concrete finite state | For every face reconstruct demand, centroid/prestress action, selected bars, effective depth, automatic/user web width, area, material design values, all method-specific VRd,c intermediates and resistance, concrete utilisation, validity, and genuine PASS/FAIL state. No finite field is optional. |
| Linked finite state | When links are enabled reconstruct link geometry/strength, lever arm, cot bounds, all method-specific link and strut intermediates, VRd,s, VRd,max, VRd, utilisation, longitudinal shear force, angle/range state, and genuine PASS/FAIL. Replay the retained 1501-point minimax shared-cot selector from original bands and low-level objectives; candidate cot and candidate governing selection are never inputs. |
| Danish causal provenance | The DK v_min method-value step is an explicit dependency of the floor and VRd,c chain. The DK nu_v method-value step is an explicit dependency of nu_v, VRd,max, VRd, linked utilisation, and verdict. Unchanged base equations retain base provenance; no DK result is explained only by an edition label. |
| Candidate closure | A finite candidate must contain every advertised concrete and linked field, per-face `shear_metric`/`shear_status`, selected governing face/domain, and per-direction aggregate status in exact order. The trace reconstructs rather than trusts duplicated selected-face state. No generic cross-direction utilisation or PASS/FAIL is created. |
| Registry and tamper closure | Fix method, lifecycle/source/citation, axes, branch, cardinality, result state, step order, dependencies, quantity roles, units, and full source metadata. Reject missing/duplicate/wrong-order direction or face; wrong method/edition/source/citation/axis/sign/action/dependency; coherent demand/resistance/utilisation/verdict/cot tamper; material/provenance and same-kind swaps; stale input/result/seal/content; unrelated-family masking; branch promotion; non-finite finite fields; omission; and dimensional substitution. |
| Independent evidence | Test-only oracles start from original inputs and use retained low-level geometry/shear/plastic kernels, plus an independently coded selector scan. They do not call the production CT-006 builder/validator or consume candidate governing choices. One numerical oracle covers each distinct 2005 and 2023 equation set; base/DK NDP variants are tabulated. A dependency control proves every used shared leaf reaches the final. |
