Open **Manual** in Sector for the input field guide, calculation methods,
worked examples and source references. The manual is generated by the running
application, so its version follows the application you are using.

The source runtime is 64-bit CPython 3.13.15, pinned in
[.python-version](../.python-version). Current project schema is 27, with the
existing schema 25/26 migrations. The portable application includes its runtime.

## Historical records

Versioned release notes describe the version named in each file. For example,
[0.96.3 notes](v0963_release_notes.md) record Part A; they do not describe the
current interface or establish completion of later work.

The `pr*_acceptance.md`, `g1*_acceptance.md`, versioned acceptance documents,
`v*_pr_programme.md` and `v*_decision_register.md` files retain the scope,
decisions and evidence of earlier work. The
[0.93 decision workbook](sector_v093_decision_register.xlsx) is also historical.
Read their stated version, commit and assessment scope before reusing them.
Historical runtime versions, deferred release labels and removed-module
references remain part of that record; the current guidance above describes
supported use today.
