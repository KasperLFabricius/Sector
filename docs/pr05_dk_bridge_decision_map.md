# PR-05 Danish bridge decision map

This map is the controlled implementation basis for F-006, F-022, and the
PR-05 portion of F-043. It was prepared from the local Design Basis library.
The main standard and Danish National Annex were read separately. The
`DS/EN 1992-2:2005 + AC:2008` method delivered by PR-04 is the inherited base;
only the evidenced Danish changes below may override or add to it.

Sector does not infer an infrastructure manager, bridge class, environmental
class, execution/control class, consequence class, authority approval, or
project dispensation. A missing, conflicting, or unmapped selection does not
change a calculation and cannot produce an unqualified selected-standard
`PASS`.

## Deliberate PR-05 boundaries

- Sector retains the PR-04 base calculation whenever the map says
  **inherited** and no exact Danish override applies.
- Method A brittle-failure analysis, the Danish shear additions, construction
  joints, transverse/interim crack cases, nonlinear global analysis, and
  authority-specific rules without complete inputs remain blocking
  `NOT ASSESSED` when applicable.
- Required decompression is never derived from a crack-width result. It remains
  `NOT ASSESSED` until a correctly routed quasi-permanent concrete-stress
  response with complete solver provenance is present.
- The static DK NA annex-availability table is printed for routing only. Because
  PR-05 has no typed applicability and complete analysis evidence for applicable
  Annex J/KK/NN/OO routes, `dk_annex_routing` remains `NOT ASSESSED`.
- Positive finite custom engineering values remain calculation inputs. The
  standard prescription is conformance metadata; malformed, Boolean,
  non-finite, or mathematically unusable values are hard errors.
- F-020 remains exactly
  `Excluded — non-code local build hygiene; user-directed exclusion`.
