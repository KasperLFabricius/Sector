# PR-08C.3c CT-008 acceptance (the Formula (6.31) screen member)

This matrix freezes the final CT-008 slice from retained main mechanics.
Sector remains `0.91`. It adds the Formula (6.31) shear-torsion
minimum-reinforcement screen member to the existing
`sector-ct-008-detailing-v1` registry (family `ct-008-detailing`; the merged
clear-spacing, transverse-links and longitudinal-minimum members are
unchanged). Every applicable member is independently mandatory; no member can
mask another. The first three rows are inherited verbatim from the PR-08C.3b
matrix's named exclusion; the ownership rows extend them per the implemented
member.
