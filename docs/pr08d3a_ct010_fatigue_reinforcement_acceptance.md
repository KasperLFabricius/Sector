# PR-08D.3a CT-010a acceptance (reinforcement fatigue)

This slice freezes the retained grouped reinforcement-fatigue mechanics while
Sector remains `0.91`. Registry
`sector-ct-010a-reinforcement-fatigue-v1`, family
`ct-010-reinforcement-fatigue`, contains one assessment per retained
spectrum/solver-element pair and one `reinforcement-output` aggregate. The
retained application invalid state is a separate failed member. Concrete
fatigue values remain PR-08D.3b scope.

| Family or invariant | Frozen acceptance |
| --- | --- |
| Applicability and branch order | A successful family exists when fatigue and its reinforcement check are exact `True`. Disabled fatigue carries neither candidate nor trace. A successful concrete-only payload is replayed and fully inventory/shape validated before CT-010a returns inapplicable; an empty, truncated or wrong-type payload cannot bypass validation. Presence of the frozen `valid` field selects the invalid branch before success-only Boolean/numerical parsing. |
| Successful replay | The retained application boundary is replayed through `fatigue_analysis.run_analysis`, including preparation, exact grouped-spectrum ordering, material/detail assignment, Elastic solves, mixed-bond correction and reinforcement assessment. The successful candidate must be a concrete built-in `dict` with the exact ordered 19-key inventory; `OrderedDict`, `UserDict`, missing/extra/reordered keys and altered retained values fail closed. Numeric comparison is exact, with NaN-to-NaN allowed and no tolerance reseal window. |
| Independent Elastic join | Every assessment bin is matched by position and exact name to its retained `FatigueBinState`. Cycles, convergence and bond method derive from that state. Long, fatigue-total, action-factored fatigue-total and perfect-bond total stresses derive independently from the state vectors at the assessment's solver element index; only then are the assessment fields compared. A coherent assessment/index/field-selection regression therefore fails even when authoritative assessment replay repeats the same bug. |
| S-N, damage and yield proof | From the matched Elastic stresses the graph re-derives bond-adjusted, perfect-bond and design ranges; characteristic/design reference ranges; two-slope S-N exponent and log life; log-domain Palmgren-Miner damage; governing tensile/compressive proof stress, limit and yield utilisation. Element damage, damage utilisation, governing-bin identities, yield maximum, convergence, utilisation and genuine PASS/FAIL are independently aggregated. `reinforcement-output` is worst-first over every spectrum/element assessment and binds each spectrum's governing reinforcement identity. |
| Complete input identity | `normalised-fatigue-inputs` consumes exact typed presence/value identities for every frozen scalar control, including raw `gamma_c` while concrete is disabled; `analysis_signature`; all concrete-ring vertices; bar/tendon coordinates, areas and order; element records/material IDs; concrete identity; full mild/prestress/fatigue-detail catalogues; basis; and the complete grouped spectrum table including spectrum/bin descriptions. Description-only and same-law material-ID changes alter the sealed bundle even if mechanics do not. All identity leaves reach every applicable member final. |
| Concrete exclusion fence | Concrete method, parameters, fibres, search, strength, governing-fibre values and concrete-influenced overall summaries are outside CT-010a value ownership while concrete is enabled. Their presence, exact container/dataclass/scalar types, mapping-key order, array shapes and sequence cardinalities are nevertheless recursively pinned. Same-type value changes remain for PR-08D.3b; list/mapping/null replacements fail. Reinforcement-bearing Elastic fields remain value-closed. With concrete disabled, overall summaries are reinforcement-owned and exact. |
| Invalid payload | The exact ordered 20-key built-in `dict` is replayed with `fatigue_analysis.invalid_result(inp, errors=retained_errors)`. Caller-supplied retained errors are never replaced by a fresh `validation_errors(inp)` result: empty sequences and externally caught failures are valid, and exact order/text/cardinality feed the failed final. Complete raw input and invalid-output identities are sealed; no numerical result is fabricated. |
| Factors and non-finite states | Raw entered `gamma_s`, `gamma_Ff` and `gamma_c` reach member finals. Absent/null/non-numerical excluded factors are undefined, never defaulted by the trace. Damage uses the retained logarithmic form. Finals distinguish finite, failed, positive-infinity, negative-infinity and undefined states; non-converged assessment/output finals are failed. |
| Sources, verdicts and closure | S-N/yield nodes carry exact selected DS/EN 1992-1-1:2005+A1:2014 or 2023 citations. Input preparation, Elastic replay and aggregation are project sources. Fatigue-damage and proof-stress PASS/FAIL are genuine implemented comparisons; no global compliance verdict is added. Exact registry/member IDs, axes, roles, sources, units, order and dependencies are audited. Every node is in its final dependency closure; stale hashes and coherent graph/value/source/unit/axis reseals fail. |
