# PR-08B.5 CT-005 elastic response and first-cracking acceptance

This matrix is frozen before implementation. The slice owns one unpublished
`ct-005-elastic-section-response` family and one retained long-plus-short member.
Sector remains `0.91`; CT-002 through CT-004, shear, torsion, detailing, crack
width, fatigue, limits, combinations, verdicts, UI/reporting, persistence,
packaging, workflow, publication, and version changes are excluded.

| Sign and equilibrium | Original user actions use tension-positive `N`; the solver receives compression-positive `P=-N`. Internal `[N,Mx,My]` uses tension-positive force and moments `stress*y` and `stress*x`, so it equilibrates `[N,-Mx,-My]`. The trace reconstructs the solved plane `q0+qx*x+qy*y`, concrete compression-zone area/first/second/coupling moments, passive bar/tendon and locked-prestress resultants, neutralising long-to-short contribution, residuals, and the compatible total concrete strain `epsilon_permille=(q_RST1+phi*q_long)/Ec_MPa`. |
| Retained response outputs | From original geometry, `conc_Ec`, creep, long/short actions, assigned `Es`, tendon initial strain, and the fixed 200 GPa reference modulus, reconstruct exact long, short increment, and total element stresses; total element strains; concrete-fibre stresses/strains; stress plane; neutral-axis states; extrema and governing element/fibre identities; convergence; and uncracked plus conditionally cracked transformed properties. These quantities are output-only and imply no limit or compliance verdict. |
| First cracking | Reconstruct Stage-I long and total stress planes. Prestress remains fixed while only the external action path is factored. At every original concrete vertex, the finite candidate is `max(0,(fctm-sigma_pre)/sigma_external)` when the no-prestress tensile stress is positive, or when the fixed-prestress external increment exceeds the retained `1e-9 MPa` tolerance; otherwise its state is positive infinity. The minimum candidate governs each path and the lower path factor governs overall, with the retained strict-tie rule. `lambda_cr < 1` is only the existing cracked state, not a verdict. |
| Result states | A converged reconstruction with a finite governing factor is finite. If no fibre/action path has a tensile reach, the governing factor and final state are genuine positive infinity with no large-number substitute. Invalid/non-finite inputs are rejected. A non-finite authoritative intermediate or non-converged authoritative solve yields a minimal failed trace that publishes no plane, stress, cracking factor, resistance, utilisation, or verdict and does not require candidate numerical fields. Finite promotion must traverse the complete finite reconstruction. |
| Dependency and provenance closure | Every used geometry coordinate, area, action, concrete input, bar/tendon modulus, tendon initial strain, and full assigned provenance identity reaches the final state. Full source kind/method/edition/citation, quantity role, unit dimension, expression, dependency, order, content seal, and input/result seals are exact registry contracts. Same-kind source swaps and standard/project substitutions are rejected. |

They do not call the production CT-005 builder/validator, consume candidate strain planes or governing fibres, or trust candidate stress arrays. A representative asymmetric concrete section with mixed mild bars and a prestressing tendon is mandatory. |
| Hostile closure | Reject missing/duplicate CT-005, unrelated-family masking, wrong method/source/edition/axis/fibre/sign/action/order/cardinality, disconnected dependencies, resealed plane/stress/fibre/final tamper, material/provenance role swaps, edited-law citation substitution, same-kind source swaps, stale input/result seals, finite/infinite/failed promotion, dimensional/unit substitution, and fabricated or required failure-only numerical fields.
