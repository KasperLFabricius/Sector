# PR-08D.1 CT-009 crack-width trace acceptance

Base is accepted `main` at `98a82b622d1ade333c04e36f3991664f07444c50`.
Sector remains `0.91`.

| Boundary | Frozen acceptance |
| --- | --- |
| Applicability | CT-009 is active only for exact current inputs with `mode` equal to `Elastic` or `Both`, exact built-in `sls_cw is True`, and `sls_edition == "2004"`. The 2023 method is CT-009b and is excluded. Disabled, plastic-only, uncracked, unavailable and absent elastic states do not publish calculated crack widths. |
| Family shape | Publish the available members in this exact order: long-term fine, short-term fine, and, for exact built-in `sls_dk_na is True`, long-term coarse and short-term coarse. Publish one aggregate member last. Base runs reject coarse siblings; DK runs require both coarse positions even when a case is unavailable. |
| Candidate inventory | Each calculated crack case requires the exact ordered retained result inventory: `wk`, `sr_max`, `esm_ecm`, `sigma_s`, `rho_p_eff`, `ac_eff`, `hc_ef`, `phi`, `cover`, `gov_bar`, `element_type`, `element_no`, `element_id`, `coarse`, `edition`, `kw`, `k1_r`, `kfl`, `sr_max_geometric`, `candidates`. Each candidate requires the exact retained ordered inventory emitted by `_crack_dict`. The aggregate requires exactly `value`, `case`, `governing`, `unit`, `calculation_state`. Missing, duplicate, reordered, unknown and wrong-typed retained fields are rejected. |
| Original inputs | Bind exact mode, crack opt-in, edition, code label, DK flag, member type, `sls_fctm`, `sls_phi`, `sls_k1`, both modular ratios, both elastic action triplets, tendon bond ratio, every concrete ring vertex, every bar/tendon coordinate and area, each element ID and material ID, the concrete material ID, and every aligned concrete/bar/tendon material-law value. Positive finite custom inputs remain valid. |
| Geometry closure | Effective depth, neutral axis, tension-face depth, clipped fine-band area, centroid-matched coarse-band area, reinforcement-in-band selection, nearest-neighbour spacing and cover are reconstructed from the actual immutable rings and element vectors. Every used geometry/material leaf reaches the case final and aggregate final. No scalar geometry fingerprint substitutes for the operand chain. |
| Mechanics replay | Reuse retained low-level kernels. Long-term Stage II state is independently replayed with `analyse_cracking`. Short-term crack width uses the retained combined-creep plane and retained total element stresses after removal of locked tendon prestress. Candidate selection and aggregate selection are independently reconstructed; candidate-selected governors, branch flags, widths and verdict-like fields are never trusted. |
| Formula branches | Reconstruct EC2 7.9 mean strain; EC2 7.11 close-spacing or 7.14 geometric spacing; exact per-element cover, diameter, stress and bond coefficient; fine `hc,ef`; DK cover-dependent `k3`; DK ordinary-beam `hc,ef` rule; and DK centroid-matched coarse system with `wk/2`. Candidate order is descending `wk`, then zero-based element index. |
| Upstream evidence | The retained short-term combined stress plane and per-element total stresses are project evidence already covered by CT-005. The unpublished long-term cracked plane is project replay and must cross-check every retained long-term element stress. Neither state is presented as a published standard result. |
| Provenance | Base formula steps cite local DS/EN 1992-1-1:2004 with A1:2014 and AC:2010, clauses 7.3.4 and equations 7.8, 7.9, 7.11 or 7.14 plus Figure 7.1 where applicable. DK-only steps cite local DS/EN 1992-1-1 DK NA:2024 revision 2024-02-01, clauses 7.3.2(3), 7.3.4(1)/(3), and Figure 7.100 NA. User/project values remain input or project evidence. Project-selected bridge labels do not invent bridge-specific mechanics or compliance. |
| States | Calculated case finals are finite output quantities only. Invalid/non-converged retained states publish one minimal failed member with no fabricated width, resistance, utilisation or engineering verdict. Unavailable/uncracked states publish one minimal undefined aggregate member reflecting the exact retained `NOT APPLICABLE` state. |
| Exactness | Candidate output and replayed finite numbers compare by exact floating-point identity, including signed zero and NaN equality where retained failure evidence requires it. No tolerance window admits adjacent-float tampering. Complete expected bundles are rebuilt during validation, so coherent reseals, stale hashes and downstream-chain tampering are rejected. |
| Inert siblings | Unrelated top-level result families are inert. Retained elastic siblings outside the frozen crack boundary remain present, positioned and type-pinned where they are dependency evidence; they are not silently accepted as replacement mappings or lists. |
| Product identity | Crack widths are output quantities only. CT-009 publishes no PASS/FAIL status, allowable-width comparison, compliance claim, multidirectional overlay, restored legacy schema or standards authority claim. |
