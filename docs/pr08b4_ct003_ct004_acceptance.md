# PR-08B.4 CT-003 radial and CT-004 axis-interaction acceptance

This matrix is frozen before implementation. The slice owns only the unpublished
CT-003 radial family and the separately required CT-004 x- and y-axis families.
Sector remains `0.91`; CT-005 and later families, presentation, persistence,
packaging, workflow, publication, and version changes are excluded.

| Family or invariant | Frozen acceptance |
| --- | --- |
| CT-003 identity | Exactly one `ct-003-radial-utilisation` family and one member are required. Its calculation method is the immutable section material-method identity; the radial selector is an uncited project source. Exact standard editions and citations come only from the concrete, bar, and tendon laws actually assigned to the solve. |
| CT-003 shape | Derive the closed-envelope member count and angle order only from requested `v_min`, `v_max`, and `v_inc`. Every member Mx/My result depends transitively on requested axial action, exact geometry, every assigned material-law value, and its declared angle. Radial demand depends on the original applied Mx/My action; resistance, utilisation, selection, and genuine verdict follow the authoritative selector. |
| CT-003 states | A converged nonzero-demand selection is finite-selected. Zero demand is an explicit finite zero-demand branch with no fabricated resistance or selected member. A failed sweep, missed ray, non-finite selector result, or missing resistance is an explicit failed branch and publishes no resistance, utilisation, selected member, or verdict. Candidate branch state and selection must agree exactly with an authoritative replay. |
| CT-004 x identity | Exactly one `ct-004-axis-interaction-x` family and one x-axis member are required. The positive branch is angle 90 degrees in tension-to-compression order; the negative branch is angle 270 degrees in reverse compression-to-tension order. |
| CT-004 y identity | Exactly one `ct-004-axis-interaction-y` family and one y-axis member are required. The positive branch is angle 0 degrees in tension-to-compression order; the negative branch is angle 180 degrees in reverse compression-to-tension order. |
| CT-004 shape | Each axis has exactly 32 intervals per branch and therefore 66 ordered retained members. Every boundary member depends transitively on exact geometry, every assigned material-law value, the declared branch angle/order, and solver-owned axial-range evidence. The applied marker depends only on original P and the matching axis moment. No off-axis substitution or sibling-axis evidence is accepted. |
| CT-004 states | A complete converged boundary is finite. Any incomplete or non-converged authoritative branch is an explicit failed trace containing exact member identities and convergence state but no fabricated resistance, utilisation, or verdict. Candidate finite arrays are checked against replay; failed numeric arrays are not published or trusted. |
| Registry closure | The registry is declared without inspecting candidate calculations. It fixes all three family/member identities, axes, methods, source editions/citations, branch/cardinality metadata, result states, exact step order, dependencies, roles, and full sources. CT-003, either CT-004 axis, or an unrelated calculation can never mask another missing or corrupt family. |
| Independent oracle | Tests reconstruct the radial sweep/selection and both axis boundaries from original inputs using authoritative low-level plastic mechanics only. Oracle code does not call the production trace builder or registry validator and does not consume candidate-selected indices or trace intermediates. |
| Hostile closure | Reject missing or duplicate family/member, radial omission, either axis omission, wrong axis/method/edition/order/cardinality, disconnected dependencies, cross-family masking, coherent candidate tamper, stale hashes/content seals, non-finite or corrupt selection, and failure-to-finite branch promotion. Dependency controls prove every used action, geometry, and material block reaches the final result. |
